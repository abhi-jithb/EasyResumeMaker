# ATS Optimization Rules

EasyResume Maker's resume generation prompt follows these content-quality rules.

## Factuality

- Use only evidence found in the source URL content.
- Never invent metrics, employers, job titles, dates, degrees, awards, or technologies.
- Generate fewer bullets when the source content is sparse.
- Keep minimal student profiles specific and honest instead of inflated.

## Summary

- Write a concise 1-2 sentence professional summary.
- Avoid generic AI phrases such as "passionate professional", "dynamic individual", "results-driven", and "highly motivated".
- Mention role focus, technologies, domain, or work style only when supported by source evidence.

## Experience

- Convert raw descriptions into recruiter-readable bullets.
- Use ATS-friendly action verbs such as Developed, Built, Implemented, Designed, Led, Improved, Automated, Integrated, Optimized, Contributed, Maintained, and Collaborated.
- Avoid repetitive opening verbs across nearby bullets.
- Prefer 1-3 strong bullets per role unless the source clearly supports more.

## Projects

- Treat GitHub repositories, apps, demos, portfolio projects, and open-source work as projects.
- Rewrite project descriptions around what the person built, implemented, integrated, automated, or improved.
- Focus on contribution, technical scope, outcome, and tools when present.
- Do not invent stars, users, revenue, performance gains, or other metrics.

## Resume Improver

- Rewrite rough resume text into one concise, recruiter-readable sentence.
- Start with a strong action verb when natural.
- Keep the rewrite ATS-friendly and specific.
- Preserve the meaning of the original text.
- Do not add tools, metrics, users, awards, or outcomes unless they are present or directly implied.
- Avoid weak phrasing such as "responsible for", "worked on", and "helped with".

## Section Order

Generated resume data should follow this recruiter-friendly order:

1. Summary
2. Experience
3. Projects
4. Skills
5. Education
6. Leadership / Community

Leadership and community includes clubs, volunteering, mentoring, organizing, speaking, and open-source community contributions.
