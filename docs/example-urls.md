# Example URL Patterns

Use public pages with visible profile, project, skill, and experience text. Replace placeholder usernames with your own.

## Best Sources

- GitHub profile: `github.com/your-username`
- Personal portfolio: `yourname.dev`
- Dev.to profile: `dev.to/your-username`
- Hashnode blog: `yourblog.hashnode.dev`
- Public blog: `yourblog.com`
- Public personal website: `yourname.com`

## Avoid

- Private dashboards
- Localhost URLs
- URLs that require login
- Pages with only images and no visible text
- JavaScript-only portfolio pages with no rendered HTML content
