Common questions


      

        

          What URLs does EasyResume Maker support?
          ›
        

        
Any publicly accessible URL works — personal portfolio sites, GitHub profiles, LinkedIn
          profiles (public), Dev.to, Hashnode, Read.cv, personal blogs, Behance, and more. If the page is publicly
          viewable, we can read it.

      


      

        

          Is my API key safe?
          ›
        

        
Your API key is used entirely in your browser and sent directly to Groq or Google's servers
          for the AI call. We never see it, store it, or log it. When you close the tab, it's gone.

      


      

        

          How do I get a free Groq API key?
          ›
        

        
Go to console.groq.com, create a free account, and generate an API key. Groq's free tier is
          very generous — you can generate hundreds of resumes for free. Groq uses the llama-3.3-70b model which is
          extremely fast.

      


      

        

          Will the AI make up information?
          ›
        

        
No. The AI is explicitly instructed to only use information found on your page — not to
          invent or hallucinate anything. If a field like phone number isn't found, it stays empty. You should always
          review the generated resume before using it.

      


      

        

          Does this work with LinkedIn?
          ›
        

        
LinkedIn blocks most automated scrapers. For best results, use your personal portfolio site,
          a GitHub profile, a Read.cv, or Dev.to/Hashnode blog. LinkedIn export works partially on public profiles.
